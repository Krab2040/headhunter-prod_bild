Практическая задача
Вложенные роуты и обработка ошибок
 

В этом задании тебе необходимо реализовать новые доработки в репозитории «Сайт вакансий». Тебе необходимо сделать fork твоего последнего решения этого задания на GitHub и выполнить следующие пункты:

1. Реализовать табы «Москва» и «Санкт-Петербург» вместо селекта города. Для реализации табов используй компонент Tabs из Mantine. При этом каждый таб должен иметь свой роут: /vacancies/moscow и /vacancies/petersburg соответственно. На каждом табе должен быть список с карточками вакансий для соответствующего города.
